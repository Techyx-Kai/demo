# HCCSS Playwright Automation Framework

## Objective

The objective is to build a maintainable, scalable and reusable Playwright automation framework for the HCCSS application.

The work shall be performed in three phases:

1. Generate a reusable Knowledge Base.
2. Generate a Playwright Test Plan based on the Knowledge Base.
3. Generate Playwright automation based on the approved Test Plan.

The Knowledge Base is the **single source of truth** for all future Playwright development.

# General Rules

- The Knowledge Base is the single source of truth.
- Documentation must be updated before generating new tests if the application changes.
- Work module-by-module.
- Prefer maintainability over quantity.
- Reuse existing Playwright components whenever possible.
- Separate static reference data from dynamically generated transactional data.
- Design tests to be independent and executable in parallel.
- Validate both UI behaviour and database behaviour where applicable.
- Cover happy paths, negative scenarios, validation rules, and end-to-end business flows.
- Stop after completing the selected module and wait for approval before continuing.
