# Enterprise Security Audit Logging Framework Analysis & Design Prompt

## Objective

Analyze the entire Spring Boot application and design an enterprise-grade Security Audit Logging Framework.

The framework shall support Java 21 and Spring Boot 3.

The framework shall integrate with the existing Enterprise Logging Framework (EFK).

The framework shall be reusable across multiple Spring Boot applications.

The implementation shall require minimal configuration.

The framework shall automatically discover metadata from the application instead of relying on large application.properties or application.yml configurations.

The purpose of this task is NOT to immediately generate code.

The AI shall first analyze the project and generate an Audit Review Specification.

Only after the review specification is completed should the implementation be designed.

# Expected Outcome

The final solution shall:

- automatically discover all controllers annotated with `@SecurityAudit`;
- automatically discover request DTOs, form objects, query parameters, path variables, model attributes, multipart fields, and JSON request bodies;
- generate an Audit Review Specification with AI recommendations for logging, masking, classification, and masking patterns;
- leave the final logging and masking decisions to application reviewers;
- support React and Spring Boot REST APIs using `application/json`;
- eliminate the need for large `application.properties` configurations;
- centralize audit metadata in a lightweight optional `audit-metadata.yml`;
- produce standardized enterprise security audit logs that integrate with the existing EFK logging standard;
- be reusable, extensible, and suitable for enterprise governance across multiple applications.
